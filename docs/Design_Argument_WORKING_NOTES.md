## 섹션 1 — The Person (재료 수집 중)

**호칭 / 정보**
- 문서 표기: "할아버지" (외할아버지)
- 연세: 미확인 — 가족에게 확인 필요
- 관계: 외할아버지

**하루 (※ 일부 전언 기반 — "~같아" 표현, 확정 관찰로 보강 필요)**
- 주로 집에서 쉬심
- 산책 하심
- TV 보심
- 할머니랑 얘기하심
- 마당일 같은 건 잘 안 하심

**수술 전의 할아버지**
- 까칠하셨음
- 말이 많으셨음
- 노래 부르는 걸 엄청 좋아하셨음
- → 이제는 노래를 못 부르심

**떠오르는 장면 / 핵심 이미지**
- 할아버지를 떠올리면 → 목에 구멍 (수술 흔적)
- 꿈 혹은 일상의 재미를 잃으신 것 같음 (대화랑 노래)
- → 그래서 할아버지의 목소리를 되찾아주고 싶음

## 섹션 2 — The Problem (재료 수집 중)

**수술 시기 / 배경**
- 수술: 약 6~7년 전
- 할아버지 인생에서 은퇴를 맞이하고, 은퇴 후 삶을 누리기 시작하던 시기
- 암을 늦게 발견 → 당시 사용자는 어렸어서 상황은 잘 모름
- 엄마가 많이 울고 슬퍼하셨음

**일상에서 곤란을 겪는 구체적 순간**
- [할아버지 직접 인터뷰] 사람들과 대화할 때 글로 적어서 해야 함 → 소통이 제대로 안 됨, 다른 사람들이 기다리게 됨 → 그게 불편하다고 답하심
- [엄마 전언] 할머니랑 둘이 사심. 할머니에게 문제가 생겼을 때(응급) 신고 후 주소·상황 설명을 못 함 → 안전 문제

**현재 workaround(종이 글쓰기)의 한계**
- [엄마 전언] 글로 써서 대화하는 걸 힘들고 불편해하심
- → 그게 불편하니까 할아버지와의 대화가 거의 없음

**부가 사실 (문제의 배경)**
- [엄마 전언] 맛을 잘 못 느끼심, 죽 같은 것만 드셔야 함

**보강 필요 (다음 답변)**
- [ ] 출처 구분 명확히: 어디까지가 할아버지 직접 인터뷰, 어디부터가 엄마 전언인지 — Research Documentation에 정직하게 표기
- [ ] "다른 사람을 기다리게 하는 게 불편하다" — 할아버지가 종이에 쓰신 표현인지, 말로 전하신 건지 (인용 정확도)
