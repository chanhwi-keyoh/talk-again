# Evidence — Talk Again

This folder holds the raw evidence behind the project:
- Screenshots of family conversations (KakaoTalk) about my grandfather's daily life and communication
- Notes from video calls
- Photos / recordings of grandfather using the prototype
- Any other primary material that grounds the Design Argument and User Testing claims

## How to add a file

1. Save the file here with a short descriptive name, e.g.
   - `katalk_mom_2026-05-10_daily-routine.png`
   - `katalk_grandma_2026-05-22_paper-workaround.png`
   - `videocall_2026-05-26_first-tap.mp4`
2. **Redact private info before committing.** Use a black box (or any image editor) to cover:
   - Phone numbers
   - Full street addresses
   - Real names of people who haven't given consent
   - Anything sensitive
3. Reference the file in the relevant doc:
   - `docs/User_Testing_Evidence.md` for prototype-use evidence
   - `docs/Research_Documentation.md` for pre-build interviews / observations
   - `docs/Design_Argument.md` if a quote drives the thesis

## Why this folder exists (for the grader)

Grading checklist explicitly asks for "Documented evidence of the real person using the prototype" and "Research is specific — interview quotes, environmental context, observed pain points." This folder is where those primary artifacts live.
